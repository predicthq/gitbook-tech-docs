# Loop Links

Loop Links are unique URLs that let anyone - frontline staff, store managers, distributed teams - submit missing events and report incorrect ones, without needing PredictHQ accounts. Submissions are reviewed by PredictHQ's data team, and accepted changes are integrated into the event record.

[Create a Loop Link](create-a-loop-link.md) per team or location, or see [Integrate with Loop Links](https://app.gitbook.com/s/tNhzHETmXsrWeVBndqqJ/integrations/integration-guides/integrate-with-loop-links) to embed submission into your own tools.
