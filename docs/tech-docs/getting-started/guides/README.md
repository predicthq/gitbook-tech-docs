# Guides

Task-level guides for working with PredictHQ data and APIs, grouped by topic: [geolocation](geolocation-guides/), [dates and times](date-and-time-guides/), [Events API](events-api-guides/), [Features API](features-api-guides/), [Forecasts API](forecasts-api-guides/), [live TV events](live-tv-event-guides/), and [Beam](beam-guides/). Guides for BI tools and data warehouses live with the [integrations](../../integrations/third-party-integrations/) they serve.

Guides answer "how do I do this specific thing." For what to build in the first place, start with [How to use PredictHQ](../how-to-use-predicthq.md) and the [Standard Integration Pattern](../../integrations/integration-guides/standard-integration-pattern.md) - the guides here fill in the details of whichever path you're on.
