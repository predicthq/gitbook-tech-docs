# Attribution

If your plan requires attribution (check your plan details in the WebApp), include the text `Events by PredictHQ` wherever you display our data. You can also include a hyperlink to [predicthq.com](https://www.predicthq.com/).

Make the attribution text clearly visible to users and place it close to the data. Ideally, it should be visible to the user at the same time as the data itself. If this is not practical, e.g. in a mobile app with limited space, you may place it in a **Settings** or **About** page.
