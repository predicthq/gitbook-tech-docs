# Algorithms

The forecasting algorithms available to Forecasts API models. Most integrations use the default - it's chosen to perform well across industries - but the list lets you see what's available and pin a specific algorithm when you have a reason to.

The Forecasts API has these algorithms:

* `phq-xgboost` is the default algorithm for every industry.
* `phq-cffm` is in beta. It is optimized for the named industries `restaurants` and `retail`, and it accepts only those industries.
