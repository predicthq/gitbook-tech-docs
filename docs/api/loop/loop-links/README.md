# Loop Links

Loop Links are unique URLs that let anyone - frontline staff, store managers, distributed teams - submit missing events and report incorrect ones, without needing PredictHQ accounts. Submissions feed PredictHQ's human-in-the-loop verification: accepted corrections improve the verified event record your models and grounded AI systems rely on.

[Create a Loop Link](create-a-loop-link.md) per team or location, or see [Integrate with Loop Links](https://app.gitbook.com/s/tNhzHETmXsrWeVBndqqJ/integrations/integration-guides/integrate-with-loop-links) to embed submission into your own tools.
