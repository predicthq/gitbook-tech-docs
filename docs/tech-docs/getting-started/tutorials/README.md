# Tutorials

Tutorials teach by doing: a fixed path with sample data, built and verified against the live API, where you finish with a result you produced yourself. No prior PredictHQ knowledge is assumed - a free trial account is enough.

* [Measure the forecast lift on sample data](measure-the-forecast-lift.md) - build the recommended integration end to end and finish with a measured accuracy improvement, in about 15 minutes.

Already know what you're building? The [guides](../guides/) cover specific tasks, and [How to use PredictHQ](../how-to-use-predicthq.md) routes you to the recommended path for your job.
