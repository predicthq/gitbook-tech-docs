# PredictHQ data

What's inside a PredictHQ event record and the predicted attributes layered onto it. These attributes are what make the data usable in models and AI systems: verified events enriched with [predicted attendance](predicted-attendance.md), [predicted end times](predicted-end-times.md), [predicted event spend](predicted-event-spend.md), [impact patterns](impact-patterns.md), and [rankings](ranks/).

Start with [Event categories](event-categories/) to understand what kinds of real-world activity are covered, then [Ranks](ranks/) to understand how impact is scored. [Data accuracy](data-accuracy.md) covers how the data is verified - the property that grounding and forecasting both depend on.
