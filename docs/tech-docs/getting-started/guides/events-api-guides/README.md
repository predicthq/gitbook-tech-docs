# Events API Guides

Guides and notebooks for working with event records. [Filtering and Finding Relevant Events](filtering-and-finding-relevant-events.md) is the worked walkthrough of Events API query mechanics, and the visualization guides cover [heatmap calendars](displaying-events-in-a-heatmap-calendar.md) and [maps](displaying-events-on-a-map.md). Notebooks by category: [attendance-based](attendance-based-events-data-science-guides.md), [non-attendance-based](non-attendance-based-events-data-science-guides.md), [severe weather](severe-weather-events-data-science-guides.md), [academic](academic-events-data-science-guides.md), and [venues](working-with-venues.md).

The Events API is for discovery, explainability, and building a grounding corpus - individual verified records your systems and users can inspect. It is not the way to build model features: aggregating events by hand introduces noise, and the [Features API](../features-api-guides/) exists so you don't have to. See [Which API Should I Use?](../../core-concepts/which-api-should-i-use.md) if in doubt.
