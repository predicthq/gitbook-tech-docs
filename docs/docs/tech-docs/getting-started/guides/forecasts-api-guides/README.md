# Forecasts API guides

Guides for the Forecasts API - event-driven demand forecasts without building or maintaining your own model. Beam runs automatically; you supply demand data and consume forecasts with explainability built in.

Recommended order:

1. [Getting started with Forecasts API](getting-started.md) - the full train, forecast, retrain lifecycle
2. [Understanding forecast accuracy metrics](understanding-forecast-accuracy-metrics.md) - reading MAPE and the baseline comparison, so the lift is measured on your own demand
3. [Troubleshooting guide for Forecasts API](troubleshooting.md) - when results don't look right

The Forecasts API also runs well inside multi-model setups - as one candidate in a champion-challenger selection or an ensemble alongside your existing forecasts.
