# PredictHQ data

What's inside a PredictHQ event record and the predicted attributes layered onto it. These attributes are what make the data usable in models and AI systems: verified events enriched with [Predicted Attendance](predicted-attendance.md), [Predicted End Times](predicted-end-times.md), [Predicted Event Spend](predicted-event-spend.md), [Predicted Impact Patterns](impact-patterns.md), and [rankings](ranks/).

To understand what kinds of real-world activity are covered, start with [Event categories](event-categories/). To understand how impact is scored, read [Ranks](ranks/). [Data accuracy](data-accuracy.md) covers how the data is verified - the property that grounding and forecasting both depend on.
