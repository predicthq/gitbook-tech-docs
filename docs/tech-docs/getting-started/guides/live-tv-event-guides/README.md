# Live TV event guides

Live TV events cover major broadcast sports in the United States, with predicted viewership by county - demand that arrives through screens rather than gates. These guides cover finding broadcasts [by county](find-broadcasts-by-county-place-id.md), [by coordinates](find-broadcasts-by-latitude-and-longitude.md), [by event](find-all-broadcasts-for-an-event.md), and [by sport](find-broadcasts-for-specific-sport-types.md), plus [aggregation](aggregating-live-tv-events.md). The Live TV notebook series lives in [Data science notebooks](../../data-science-notebooks.md).

For modeling, use the `phq_viewership_*` features in the [Features API](https://app.gitbook.com/s/kEFs8urDbSJqBmXUI3Lv/features/get-features) rather than aggregating broadcasts yourself.
