# Integration Guides

How to put PredictHQ into production.

Start with the [Standard Integration Pattern](standard-integration-pattern.md) - the reference architecture for forecasting and decision systems, from location setup through features, events, and explainability. Grounding AI systems inside your environment extends the same architecture: see [Internal grounding](internal-grounding.md). [Keep Data Updated via API](keep-data-updated-via-api.md) and [Loading Event Data into a Data Warehouse](loading-event-data-into-a-data-warehouse.md) cover the do-it-yourself path when managed delivery isn't an option, and [Integrate with Loop Links](integrate-with-loop-links.md) lets frontline teams feed event corrections back into the data.

For which path to build at all, see [How to use PredictHQ](../../getting-started/how-to-use-predicthq.md).
