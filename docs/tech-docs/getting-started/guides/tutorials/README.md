# Tutorials

Step-by-step tutorials, from finding events to production model inputs. They are not all equal:

* **The production path** is [Improving Demand Forecasting Models with Event Features](improving-demand-forecasting-models-with-event-features.md) - if you're building a forecasting integration, start there.
* [Filtering and Finding Relevant Events](filtering-and-finding-relevant-events.md) teaches Events API query mechanics - useful for exploration and explainability surfaces.
* The tool tutorials ([Power BI](using-event-data-in-power-bi.md), [Tableau](using-event-data-in-tableau.md), [Excel](connecting-to-predicthq-apis-with-microsoft-excel.md), [heatmap calendar](displaying-events-in-a-heatmap-calendar.md), [maps](displaying-events-on-a-map.md)) are for analysis and reporting - good for evaluating the data, not a substitute for the [Standard Integration Pattern](../../../integrations/integration-guides/standard-integration-pattern.md) in production.
* [Loading Event Data into a Data Warehouse](loading-event-data-into-a-data-warehouse.md) covers API-based loading - for most production deployments, [managed delivery](../../../integrations/third-party-integrations/) is the better path.
